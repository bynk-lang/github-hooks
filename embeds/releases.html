A release is counted when it is published and is neither a draft nor a pre-release; pre-releases are listed and marked but count towards nothing else. "Merge to release" runs from a pull request's merge to the publishing of the first release that shipped it, matched by commit, over pull requests by people that a release in the window shipped; the 95th percentile is alongside. "Waiting to ship" counts pull requests by people merged since the latest release. A repository's pull requests are measured from when it began to be recorded, and a release's count of what it shipped is left blank when that can't be known. The release workflow is the one that ran on a release's tag, counted over its runs on tags. Data: /metrics/releases, /metrics/releases/recent. Source: bynk-lang/github-hooks, written in Bynk.
