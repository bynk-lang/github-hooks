Times are medians over pull requests merged in the window, with the 95th percentile alongside. "Ready to merge" runs from when a pull request was marked ready for review (or opened, if it opened ready) to its merge; pull requests that became ready before the service started recording are left out of it, and each figure says how many it counts. "In the queue" runs from the last time it joined the merge queue to its merge. Bots' pull requests are counted apart. An open pull request is stale when it has been ready for more than 7 days and isn't in the queue. Data: /metrics/prs, /metrics/prs/open. Source: bynk-lang/github-hooks, written in Bynk.
